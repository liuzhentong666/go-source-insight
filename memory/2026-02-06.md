## 🎯 功能特性

### 支持的日志级别
| 级别 | 数值 | 说明 | 使用场景 |
|------|------|------|----------|
| debug | -4 | 最详细的日志 | 开发调试 |
| info | 0 | 常规信息 | 正常运行 |
| warn | 4 | 警告信息 | 潜在问题 |
| error | 8 | 错误信息 | 发生错误 |

### 支持的日志格式
- **Text 格式**：人类可读，适合终端输出
- **JSON 格式**：机器可读，适合日志分析

### 支持的日志输出
- **stdout**：标准输出
- **stderr**：标准错误
- **file**：文件输出

### 配置优先级
```
命令行参数 > 环境变量 > 配置文件 > 默认值
```

### 1. 工厂模式
使用工厂模式创建不同类型的 logger，灵活且易于扩展

### 2. 配置优先级

### 3. 结构化日志

# 后续范围

当前交付 CLI、API 和 Web 工作台的源码扫描、静态分析、Ollama 代码问答，以及单实例本机部署。API 复用根模块、持久有界任务、认证、本机完整路径读取及兼容源码绑定；Web 复用项目/任务契约，提供同源代理和独立镜像。真实 API 服务、本地源码目录入口及 Web 真实浏览器与模型全链路已在隔离栈独立验收，见 [最终验收记录](progress/2026-10-10-final-acceptance.md)。上述历史记录对应当时版本，不代表新宿主读取模式已完成真实部署验收。以下项目暂不属于核心功能验收。

## 外部模型 API

- 增加其他模型供应商的聊天和向量接口，保持现有服务边界。
- 通过环境变量或本地覆盖配置注入凭据；仓库和文档仅使用通用示例。
- 增加连接校验、超时、限流与错误处理，并验证不同模型的向量维度。

## Web 平台

- 源码上传、Git 拉取、网页自动授权主机目录；当前本机部署可选一次源码目录，各项目的网页完整路径只限已选根，旧项目映射继续兼容。
- 流式问答、持久会话历史、完整服务端任务列表；当前任务列表仅保存本浏览器记住的任务 ID。
- 协调后端 HTTP、代理和客户端的长期问答期限；当前后端写入期限固定为 300 秒。
- 多副本、分布式任务协调、远程 HTTPS 和协作权限仍不属于当前单实例本机部署。
- 依赖：移除或升级未导入的 `echarts`、`@monaco-editor/react`（含 `monaco-editor`/`dompurify`），清除剩余 3 个 moderate 审计条目；npm 旧审计接口下线后补做开发/构建依赖复审。
- `API_PORT` 默认 8087 可能与本机其他服务冲突；部署脚本可在端口被占用时给出明确提示。

## 核心能力后续增强

- `doctor` 的聊天模型能力预检暂缓；当前不会验证模型是否支持聊天，需自行将 `CHAT_MODEL` 配置为聊天模型。
- 增量索引、历史快照列表、回滚与清理命令；当前使用整库快照，验证完成后发布内部别名，保留旧数据。补充保留数量/磁盘预算策略，以及异常中断后遗留快照的识别与清理。
- 迁移到新的 Milvus Go SDK，并在真实空结果回归通过后移除旧客户端兼容处理。
- 改善符号与关键词检索、结果排序和上下文选择，并增加问答依据与准确性的评估。
- 扩展静态分析规则与误报评估。
- 从测试骨架升级为有实际断言的测试生成。
- 提供可选 GPU 部署配置和自动化容器端到端验证。
- 多人协作及远程服务部署；当前 API 已实现项目/任务归属隔离。

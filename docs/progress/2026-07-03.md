## 设计决策

### Q1: Ask 无检索结果行为

**决定**：返回 `AnswerResult{Answer: "", Sources: nil}, nil`（exit 0）。系统正常运行，只是没有可引用的内容，不应报错。

### Q2: RAGOptions 是否独立于 config.RAGConfig

**决定**：方案 A — `internal/ai` 独立定义 `RAGOptions`，调用方（CLI 命令层）负责 `config.RAGConfig → RAGOptions` 转换。避免 `internal/ai` 依赖 `internal/config`，保持包边界干净、测试隔离。

## 其他发现

### `go build ./...` 全量超时诊断

根因：WSL 9p 文件系统 + `web/node_modules` 27000+ 文件。`go build ./...` 递归遍历时 stat 走 9p 协议到 Windows 宿主，I/O 延迟累加导致 120s 超时。`go build ./internal/... ./cmd/...` 范围内构建 4s 完成。

**影响评估**：不影响后续开发。Task 5-10 全部在 `internal/ai`、`internal/cli/commands`、`cmd` 三个目录下，显式指定路径完全覆盖。

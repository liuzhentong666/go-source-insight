# 2026-06-28 GoSource-Insight CLI 改造进度

## 本轮目标

对 GoSource-Insight 进行 CLI 优先改造升级：
- `scan`：扫描 Go 项目结构，统计文件/行数/跳过目录
- `analyze`：对 Go 文件或目录执行静态规则分析（复杂度/安全/Bug）
- 打通主链路，保障代码质量与可信度

## 工作流程

按项目开发默认工作流推进：基线 → plan → 质疑 → 执行 → 审查 → 追问 → 二次执行 → 验收
